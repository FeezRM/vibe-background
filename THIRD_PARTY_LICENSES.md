# Third-party components

Vibe Background is GPL-3.0-or-later. It downloads or bundles the following. Model weights are
fetched on first use from the pinned revisions in `engine/vibebg_engine/models/registry.py`.

## AI models

| Used for | Model | License |
|---|---|---|
| Cutout, Fast tier | [RobustVideoMatting](https://github.com/PeterL1n/RobustVideoMatting) MobileNetV3 | GPL-3.0 |
| Cutout, Balanced and Max tiers | RobustVideoMatting ResNet50 | GPL-3.0 |
| Cutout, Max tier edge refinement | [ViTMatte](https://github.com/hustvl/ViTMatte) small, Distinctions-646 ([weights](https://huggingface.co/hustvl/vitmatte-small-distinctions-646)) | MIT (code), Apache-2.0 (weights) |
| Depth-of-field blur | [Depth Anything V2 Small](https://huggingface.co/depth-anything/Depth-Anything-V2-Small-hf) | Apache-2.0 (only the Small model; larger variants are non-commercial and are not used) |
| AI Relight (experimental) | [IC-Light](https://github.com/lllyasviel/IC-Light) fbc ([weights](https://huggingface.co/lllyasviel/ic-light)) | Apache-2.0 (code), CreativeML OpenRAIL-M (weights) |
| AI Relight base model | [Realistic Vision 5.1](https://huggingface.co/stablediffusionapi/realistic-vision-v51) (Stable Diffusion 1.5) | CreativeML OpenRAIL-M |

CreativeML OpenRAIL-M allows commercial use of outputs but carries use-based restrictions (for
example, no generating content that violates laws or harms people). Read the license before
using AI Relight.

## Built-in backgrounds

Photos are CC0 from Wikimedia Commons. Each preset's `manifest.json` names the author and links
the source page. The animated loops (`warm-bokeh`, `aurora`, `studio-sweep`) are generated by
`scripts/make_loops.py` and released with this project.
